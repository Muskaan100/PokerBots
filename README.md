# PokerBots

A competitive Discard Hold'em poker bot built for the Antigravity / Google DeepMind competition.

## Features
- Fast hand evaluator (≈10× speedup over naive Python implementation)
- Tight time‑bank management (≤ 30 s per leg, adaptive simulation budget)
- Monte‑Carlo equity estimation with configurable simulation limits
- Smart discard optimisation (Monte‑Carlo evaluation of each discard option)
- Lightweight opponent modelling (VPIP, aggression factor)
- No external dependencies – pure Python 3.11 standard library

## How to run
```powershell
# From the repository root (C:\PokerBots)
python C:\PokerbotStarterkit\Starter_Kit\engine.py bot.py \
    C:\PokerbotStarterkit\Starter_Kit\example_bots\random_bot.py \
    --seed 12345 \
    --log-dir C:\PokerBots\logs \
    --stage 1
```
*Add `--no-time-limits` for debugging or when you want to ignore the per‑leg time bank.*

## Repository layout
- `bot.py` – the final competitive bot (contains hand evaluator, time manager, equity calculator, opponent model, and betting engine).
- `README.md` – this file.
- `logs/` – generated by the engine; contains `match.log`, `A_leg*_stderr.txt`, `B_leg*_stderr.txt`.
